This server is read-only by construction. Every database is opened file:…?mode=ro and the app has no non-GET routes, so the UI cannot touch the experiment. The window is a window, not a door.

The API is live and documented at /docs:

  • GET /api/health — databases, counts, feed provenance
  • GET /api/bars?tf=15m — session-aware candles, provenance per bar
  • GET /api/indicators?tf=15m&set=ema50,ema200,rsi,macd,bb — computed by executor.indicators, the same code the checklist runs
  • GET /api/signals · GET /api/arms · GET /api/trades
  • GET /api/huntplan · GET /api/noshots · GET /api/histogram
  • GET /api/calibration · GET /api/rollup

Bars come from data/barcache.db, a cache and not a record: delete it and a re-fetch rebuilds it. Nothing here is worth backing up.
